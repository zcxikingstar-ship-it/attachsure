# Product decision

AttachSure is a final pre-send companion for ordinary copy/paste workflows: email, WeChat, and browser chats.

It is intentionally not a file-transfer system, an AI-session handoff tool, a cloud drive, or a delivery-checklist comparator. It starts with the actual outgoing message plus the files the sender has selected, looking for contradictions a recipient would otherwise discover after sending.

The local-only boundary is product-critical: no file content reading, upload, login, message sending, recipient access, or delivery claims. Its output is a human-readable note and an optional local JSON check record; the sender remains responsible for the final attachment and send action.
